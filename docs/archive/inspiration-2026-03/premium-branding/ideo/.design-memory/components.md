# Components

## Component cues
- Buttons and chips stay minimal and secondary to the main proof surface.
- Tabular surfaces should stay calm, aligned, and function-first.
- Case-study carriers should read as editorial proof, not mosaics.

## Layout cues
- Layouts should read as curated proof sequences with strong margins and clear grouping.
- Composition should anchor around one product frame or proof surface before any supporting insets.
- Observed section language suggests a structured page rhythm around Planes, supply chains, and automobiles, Featured work, Accelerating the future of air travel.
