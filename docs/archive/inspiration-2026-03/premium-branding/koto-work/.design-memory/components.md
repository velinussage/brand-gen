# Components

## Component cues
- Project showcases should prioritize one convincing proof move per frame.
- Case-study carriers should read as editorial proof, not mosaics.

## Layout cues
- Layouts should read as curated proof sequences with strong margins and clear grouping.
- Composition should anchor around one product frame or proof surface before any supporting insets.
- Spacing should stay generous enough that the focal move reads in under five seconds.
- Observed section language suggests a structured page rhythm around Channels, Explore, Channels.
