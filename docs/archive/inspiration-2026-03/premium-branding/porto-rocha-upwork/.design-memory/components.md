# Components

## Component cues
- Navigation chrome should stay restrained and low-noise.
- Forms should use low-friction fields with clear hierarchy and minimal decoration.

## Layout cues
- Layouts should read as curated proof sequences with strong margins and clear grouping.
- Composition should anchor around one product frame or proof surface before any supporting insets.
- Observed section language suggests a structured page rhythm around About us, YOYOYO, Robinhood Market.
