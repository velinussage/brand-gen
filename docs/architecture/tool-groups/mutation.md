# Mutation tools

Use these instead of direct file edits.

- Scratchpad: `brand_append_forbidden_pattern`, `brand_append_custom_scratchpad_note`
- Learnings: `brand_promote_learning`, `brand_promote_style_policy`
- Identity: `brand_update_palette`, `brand_update_typography`, `brand_update_devices`
- Motion: `brand_set_motion_grammar`
- Prep assets: `brand_export_design_tokens`, `brand_extract_inspiration`, `brand_consolidate_inspiration`
- Review/feedback: `brand_submit_review`, `brand_feedback`
- Workspace/policy: `brand_switch_brand`, `brand_set_policy`, `brand_approve_action`, `brand_reject_action`

Every mutation is local unless policy says otherwise. Hosts should enforce `policy_class` from the canonical registry.
